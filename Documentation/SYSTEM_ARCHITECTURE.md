# System Architecture: Project 06 Agriculture Drone

## Subsystem Breakdown
1. **Airframe Subsystem**: Central sandwich plates, 6 radial arms, folding hinges, safety-yellow aerodynamic canopy.
2. **Propulsion Subsystem**: 6x 8318 outrunner brushless motors, 6x 30" carbon-fiber folding propellers, 6x FOC ESCs.
3. **Chemical Delivery Subsystem**: 20L tank, dual diaphragm pumps, flow meters, liquid level sensor, centrifugal atomizer nozzles.
4. **Avionics & Sensing Subsystem**: Redundant FC, RTK GNSS antennas, obstacle avoidance radars, FPV camera, telemetry.
5. **Ground Control Subsystem**: Handheld smart controller, telemetry link, autonomous mission planning interface.
